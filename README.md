
# Digital Public Infrastructure (DPI) Readiness Index — Kenya, Rwanda, Tanzania #

A comparative scoring framework assessing Digital Public Infrastructure readiness
across three East African countries, examining Kenya's market-led vs. Rwanda's
state-led DPI development paths and evaluating which elements of each are
realistically replicable for Tanzania.

 # Purpose #

Scores each country on 12 sub-indicators across 4 dimensions:
 - infrastructure foundation, state capacity for digital governance, digital
public stack maturity, and political economy/sustainability.
 - Rates each sub-indicator's transferability (high / conditional / low) —
distinguishing outcomes that are policy-replicable from those tied to
country-specific political or historical conditions.
 - Computes a capability score (current state) and ambition score
(stated policy target) for each indicator, and derives the alignment
gap between them.
 - Rolls indicator-level scores into a weighted composite index per
country — the headline output of the model.


# Key finding

Tanzania shows the widest capability-ambition alignment gaps of the three
countries, concentrated in digital public stack maturity (national ID
coverage, government service digitization) rather than raw infrastructure.
The transferability ratings suggest Tanzania can realistically adopt Kenya's
market-led infrastructure approach (high transferability) but cannot simply
replicate Rwanda's state-capacity outcomes (low/conditional transferability),
since those depend on political-economy conditions specific to Rwanda's
post-1994 settlement.
